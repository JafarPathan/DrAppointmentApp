# API contract (v1 draft)

> Auto-updated: any endpoint change must update this file (AGENTS.md Rule 1). The OpenAPI spec generated by the backend is the source of truth once code exists. This file is the human-readable summary.

Base URL: `https://api.<domain>/v1` · JSON · errors use RFC 7807 `ProblemDetails` · auth `Authorization: Bearer <access token>` · all list endpoints are paginated (`page`, `pageSize` ≤ 50).

Legend: 🌐 anonymous (rate-limited) · 👤 Patient · 🩺 Doctor · 🧑‍💼 ClinicStaff (with permission) · 🛡️ PlatformAdmin

## Auth

| Method | Path | Who | Notes |
|---|---|---|---|
| POST | `/auth/otp/request` | 🌐 | `{phone}` → always 202 (doesn't reveal whether the account exists). Strict rate limit |
| POST | `/auth/otp/verify` | 🌐 | `{phone, code, deviceId}` → `{accessToken, refreshToken, isNewUser}` |
| POST | `/auth/mfa/verify` | 🩺🧑‍💼🛡️ | second factor for dashboard roles |
| POST | `/auth/refresh` | 🌐 (refresh token) | rotates the token. Reuse → whole family revoked |
| POST | `/auth/logout` | any | `{allDevices?: bool}` |

**Anonymous endpoints and why:** OTP request/verify and refresh (needed before login). Public doctor search/profile/slots (discovery before signup). Nothing else.

## Status codes

`200/201` ok · `400` validation · `401` not logged in · `403` not allowed · `404` not found **or not yours** (we return 404 for others' resources so we don't leak that they exist) · `409` slot taken / conflict · `429` rate limited.
